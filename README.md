# Nata Kapitos — каркас сайту

Статичний сайт без збірки. Ніякого npm, білдів і залежностей: відкриваєте `index.html` у браузері — працює.

## Структура

```
index.html        головна
catalog.html      каталог з фільтрами
product.html      сторінка товару (product.html?sku=AM-014)
cart.html         кошик і форма замовлення
sizes.html        як визначити розмір
info.html         доставка, оплата, обмін
contacts.html     контакти
assets/style.css  усі стилі
assets/app.js     каталог, фільтри, кошик
data/products.js  ТОВАРИ — тут ви редагуєте наповнення
data/products.json той самий вміст, як довідка
```

## Як додати товар

Відкрийте `data/products.js` і скопіюйте будь-який блок. Поля:

| Поле | Що це |
|---|---|
| `sku` | Артикул. Має збігатися з іменами фото: `AM-014-1.jpg`, `AM-014-2.jpg` |
| `category` | `Весільні`, `Вечірні` або `Корсети` |
| `silhouette` | `А-силует`, `Русалка`, `Пряма`, `Корсет` |
| `price` | Число без пробілів: `18400` |
| `modelHeight` / `modelSize` | Зріст і розмір моделі на фото |
| `photos` | Скільки фото у цієї моделі |
| `featured` | `true` — показувати на головній |
| `sizes[]` | Рядок на кожен розмір: заміри виробу в см і `qty` — скільки штук є |

`qty: 0` означає, що розмір показується закресленим і його не можна замовити.

## Фото

Зараз замість фото — сірі плейсхолдери з артикулом. Коли будуть знімки:

1. Складіть їх у папку `assets/photos/` з іменами `АРТИКУЛ-НОМЕР.jpg`.
2. У `assets/app.js` функція `ph()` формує плейсхолдер — замініть її на `<img>`.

Рекомендований розмір: 1200×1600 px, вертикальні, до 300 КБ кожне (стисніть на squoosh.app).

## Публікація на Cloudflare Pages

1. Зареєструйтесь на cloudflare.com, розділ **Workers & Pages** → **Create** → **Pages**.
2. **Upload assets** — перетягніть усю цю папку.
3. Назвіть проєкт `natakapitos` — сайт буде за адресою `natakapitos.pages.dev`.

Оновлення: перетягуєте папку ще раз. Або підключіть GitHub — тоді сайт оновлюється сам після кожної зміни.

## Що ще не працює

**Надсилання замовлень — підключається одним ключем.** У файлі `assets/app.js` вгорі є блок
`NK_CONFIG`. Щоб замовлення приходили на пошту:

1. Зареєструйтесь на web3forms.com, отримайте безкоштовний Access Key.
2. Вставте його в `NK_CONFIG.web3formsKey`.

Готово — після підтвердження замовлення лист приходить на вашу пошту. Поки ключ порожній,
сайт показує текст замовлення на екрані (щоб надіслати вручну в Instagram).

Опційно Telegram (замовлення падає в телефон): створіть бота через @BotFather, візьміть токен,
а `chatId` — через @userinfobot, і впишіть їх у `NK_CONFIG.telegram`. Увага: бот-токен буде
видно у коді сайту, тому для email надійніше web3forms.

**Немає адмінки.** Товари редагуються в `data/products.js` через текстовий редактор. Якщо це незручно, наступний крок — Decap CMS: додається до статичного сайту й дає веб-інтерфейс за адресою `/admin`.

## Дрібниці перед запуском

- Фавікон уже додано: `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` у корені.
- Перевірте телефон і посилання на Instagram у підвалі кожної сторінки.
